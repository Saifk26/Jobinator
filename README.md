# Jobinator

Jobinator is an AI-assisted career document platform. It helps students, job seekers, interns and professionals create, improve and tailor resumes, CVs and LinkedIn profiles.

This repository holds the project's planning and design documentation.

## Planned features

- Account creation, secure login and account recovery
- Create a document from scratch or improve an existing one (upload, paste, or LinkedIn profile URL)
- AI content generation, rewriting and wording suggestions, always editable by the user
- Job-specific tailoring from a target title, industry or job description
- Saving drafts and exporting to PDF or DOCX
- User-controlled privacy and permission settings
- Admin monitoring and AI service configuration

## Planned tech stack

| Layer | Technology |
| --- | --- |
| Frontend | React.js, TypeScript |
| Backend | Node.js / Express |
| Data | Structured database plus file storage |
| AI | External LLM service |
| Documents | PDF/DOCX parsing, preview and export |
| Security | HTTPS/TLS, authentication, permissions |
